# محمل الفيديوهات الذكي بأعلى جودة (Video Downloader Pro)

أداة بسيطة وقوية كتمكنك من استخراج وتحميل الفيديوهات من أي موقع (يوتيوب، فيسبوك، تيك توك، إكس/تويتر، ومئات المواقع الأخرى) بأعلى دقة متوفرة (4K, 1080p, 720p أو صوت فقط MP3).

---

## 🚀 كيفية التشغيل (طريقة ساهلة بزاف)

يكفي تدخل للمجلد:
`C:\Users\Desig\.gemini\antigravity\scratch\video_downloader`

وتضغط مرتين (Double Click) على أحد الملفات:
1. **`Lancer_Interface.bat`**: كيشغل ليك التطبيق بواجهة رسومية أنيقة وسهلة الاستخدام (نافذة عادية).
2. **`Lancer_CLI.bat`**: كيشغل ليك البرنامج فسطر الأوامر (Terminal) إذا كنت كتفضل الـ CLI.

---

## ✨ المميزات:
- **أعلى جودة (Best Quality)**: كيدمج أحسن جودة فيديو مع أحسن جودة صوت تلقائياً عبر `ffmpeg`.
- **اختيار الجودة**: 4K/1080p Max / 720p / صوت فقط بصيغة MP3.
- **فحص الرابط قبل التحميل**: كيعطيك العنوان، الناشر، والمدة قبل ما تبدا التحميل.
- **شريط تقدم التحميل (Progress Bar)**: كيبين ليك النسبة المئوية وسرعة التحميل بالثانية.
- **زر مباشر لفتح مجلد التنزيلات**: ضغطة زر كتديك مباشرة للملفات المحملة.
